# UnLoQ1 — Abstract

UnLoQ1 is a web app that helps users see how much interest they can save by paying extra on their loan. It does this using a single interest-saving flow on the home page, driven by seven inputs and two results.

**Seven inputs (home page)**  
The user provides: (1) **Current Outstanding Balance**, (2) **Original Loan Amount**, (3) **Current Interest Rate (% p.a.)**, (4) **Remaining Loan Tenure**, (5) **Current Monthly EMI**, (6) **Extra Monthly Payment Capacity**, and (7) **Monthly Living Expenses**. The app uses these to compute interest savings for two scenarios.

**Two results**  
1. **Interest Saved This Month** — How much future interest is avoided if the user pays the chosen extra amount once, this month. A **“Pay now”** action takes the user to the next step for **account confirmation** (loan and bank details) to proceed with that payment.  
2. **Interest Saved Over 2 Years** — How much interest is saved if the user pays the same extra amount every month for two years. This result has a **“Set reminder”** option.

The description above focuses only on this interest-saving concept: seven inputs on the home page, two results, and the first result leading to account confirmation for paying now.
